# Pharma-Market-Access-Pricing-Intelligence-Dashboard


## Overview
This repository contains interactive Power BI dashboards designed to analyze pharmaceutical pricing, market access, and patient savings.  
The dashboards provide insights into branded vs. Jan Aushadhi medicines, cost ratios, and therapeutic category savings.

## Dashboards

### 1. Market Access & Pricing Intelligence
- Horizontal bar chart comparing **cost ratio by drug formulation** (e.g., Metformin, Sitagliptin, Insulin variants).
- Manufacturer filter (Alkem, Biocon, Cipla, Dr Reddy’s, Glenmark, Lupin, Novo Nordisk, Sanofi India, etc.).
- Key metrics:
  - **Total brands analyzed**: 165  
  - **Average branded price**: ₹244.96  
  - **Average Jan Aushadhi price**: ₹86.23  
  - **Average patient savings**: 74%  

### 2. Brand-Level Detail & Saving Explorer
- Detailed table showing **brand, manufacturer, branded MRP, Jan Aushadhi price, and savings %**.
- Examples:  
  - Amlodipine-Plus-5 (Biocon): 94.8% savings  
  - Losartan-Norm-3 (USV): 94.7% savings  
  - Sitagliptin-G-18 (Dr Reddy’s): 91.9% savings  
- Category‑wise savings chart:
  - **Cardiac**: 90%  
  - **Diabetes – Oral**: 87%  
  - **Diabetes – Insulin**: 44%
